This repository hosts the GitHub Pages site for Yundae Lee Song (formerly Jaehoon Song). The site is used to publish PDF proofs of works and related documentation.

## Purpose
- Central, public archive of PDF documents that demonstrate, verify, or illustrate my works.
- Each PDF represents a proof, paper, report, or artifact related to professional and academic activities.

## How to add documents
1. Put PDF files in a clear subfolder (suggested: `documents/` or `pdfs/`).
2. Add an entry to the site index or a dedicated listing page with a relative link:
    - Example: `[My Paper Title](documents/my-paper.pdf)`
3. Commit and push to the branch configured for Pages (commonly `main` or `gh-pages`).

## Recommended structure
- /documents/        — PDF files (keep filenames descriptive)
- /assets/           — images, supporting files
- index.md / index.html — index page listing documents and short descriptions

## Publishing
- Ensure GitHub Pages is enabled in repository settings and pointed to the correct branch/folder (e.g., `main` / `/ (root)` or `/docs`).
- After pushing changes, allow a few minutes for Pages to build and publish.
